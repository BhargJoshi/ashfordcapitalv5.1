# Videos for the Home page (About section)

Put the three video files here, named exactly:

- `ashford-1.mp4`
- `ashford-2.mp4`
- `ashford-3.mp4`

Then run `node build.mjs` (or copy them into `site/assets/video/`). They appear in the three boxes automatically.
To use other names or formats, edit the `<source src="...">` of each box in `src/pages/index.html`.
This README and `.gitkeep` are not deployed.
